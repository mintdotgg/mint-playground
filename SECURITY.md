# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting for this repository when it is
available. Otherwise, contact the Mint team privately through
[mint.gg](https://mint.gg) and include:

- The affected experience or repository path.
- Steps to reproduce the issue.
- The potential impact.
- Any suggested mitigation.

We will acknowledge the report, investigate it, and coordinate disclosure with
the reporter. This policy covers code in this repository; vulnerabilities in a
third-party dependency should also be reported to that dependency's maintainer.
