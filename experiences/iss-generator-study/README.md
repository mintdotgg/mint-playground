# ISS Generator Study

Fly between four AI-generated International Space Stations above Earth, compare their topology, disassemble Mint&#39;s 158-part build, and step inside the Destiny laboratory.

[Live demo](https://play.mint.gg/iss-generator-study) · [Source code](https://github.com/mintdotgg/mint-playground/tree/main/experiences/iss-generator-study)

Made with [Mint MCP](https://mcp.mint.gg/) as the 3D asset pipeline and
[Mint Three.js Skills](https://github.com/mintdotgg/mint-threejs-skills) as the coding workflow.

## Run locally

From the `mint-playground` repository root:

```bash
pnpm install
pnpm --dir experiences/iss-generator-study dev
```
